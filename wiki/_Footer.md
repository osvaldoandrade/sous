Sous is developed in the open at
[github.com/osvaldoandrade/sous](https://github.com/osvaldoandrade/sous).
The repository contains the control plane, gateway, scheduler, invoker
pool, Cadence poller, CLI, and runtime adapters in a single Go module,
along with the deployment manifests for Kubernetes and Docker Compose
described in the operator guides. Refer to the repository for the active
license terms, the issue tracker, the release notes, and the source for
each service, runtime, and client described in these pages.

This documentation is generated from the project's wiki source. Pages
live as Markdown files under `wiki/` in the main repository and are
published through the script described in
[Contributors Resources](Contributors-Resources); corrections,
clarifications, and new sample applications are accepted as pull
requests against that directory.
